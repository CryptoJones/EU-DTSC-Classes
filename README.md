# EU-DTSC-Classes

Coursework and notes for Eastern University's graduate programs in Data Science, Analytics, and Applied AI (MSDS / MSDA / MSAI).

## Textbooks by course

Taken from the "Software and Textbook" pages and the current syllabi posted in the program's Course Preview and Syllabi hub on Brightspace (checked October 2026). Prerequisites come from the program's Curriculum Guide (revised July 2026); DTSC 625's comes from its syllabus. A given term's section may list something different.

\*\* = a course I plan to take. ✅ = completed.
